# 📊 Módulo Dashboard

O **Dashboard** é a central executiva do FinControl onde o usuário visualiza instantaneamente sua saúde financeira.

## 🔗 Conexões
- Retornar ao [[Visao-Geral-FinControl]]
- Conectado com [[Modulo-Transacoes]] (origem dos dados de movimentação)
- Conectado com [[Modulo-Cartoes]] (exibição de faturas abertas)
- Conectado com [[Modulo-Categorias-e-Orcamentos]] (progresso do teto mensal)

## 📌 Principais Recursos
1. **Cards de KPI**: Receita total, despesas do mês, saldo consolidado e economia gerada.
2. **Gráfico de Fluxo de Caixa**: Evolução temporal de entradas vs. saídas.
3. **Distribuição por Categoria**: Gráfico donut identificando os maiores centros de custo.
4. **Atalhos Rápidos**: Botões de ação rápida para novos lançamentos e transferências.
