# 📊 Módulo Dashboard

O **Dashboard** é a central executiva do FinControl onde o usuário visualiza instantaneamente sua saúde financeira.

## 🔗 Conexões
- Retornar ao [[Visao-Geral-FinControl]]
- Conectado com [[Modulo-Transacoes]] (origem dos dados de movimentação)
- Conectado com [[Modulo-Cartoes]] (exibição de faturas abertas)
- Conectado com [[Modulo-Categorias-e-Orcamentos]] (progresso do teto mensal)

## 📌 Principais Recursos
1. **Interactive Data Cards (3D & Sparklines)**:
   - **Physics Tilt & Glare**: Inclinação tridimensional dinâmica baseada no movimento do cursor/touch com reflexo de luz.
   - **Card Flip (180°)**: Transição suave para verso analítico contendo métricas rápidas (maior lançamento, médias diárias, taxa de poupança e tendências comparativas).
   - **Sparklines Vetoriais**: Mini-gráficos SVG embutidos com tooltips magnéticos e amostragem periódica da evolução financeira.
   - **Variantes Semânticas**: Temas de cores refinados para Saldo (`primary`), Receitas (`success`), Despesas (`danger`) e Metas (`purple`/`warning`).
2. **Gráfico de Fluxo de Caixa**: Evolução temporal de entradas vs. saídas.
3. **Distribuição por Categoria**: Gráfico donut identificando os maiores centros de custo.
4. **Atalhos Rápidos**: Botões de ação rápida para novos lançamentos e transferências.
